# Demo Questions

Upload a PDF with enough text and try:
- "Summarize this document in five bullet points."
- "What are the main dates and deadlines mentioned?"
- "Explain the key terms in simple language."
- "What does the document say about [topic]?"
- "Which page supports your answer?"

Tip: Ask a question whose answer is clearly in the PDF, then try one that is not. The assistant should acknowledge when the document does not contain the answer.
